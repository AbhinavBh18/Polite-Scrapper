# The Polite Scraper

FlyRank Backend Track · Week 5 · Assignment A9

## Target classification

[Books to Scrape](https://books.toscrape.com/) is a fictional bookstore that [ToScrape](https://toscrape.com/) provides as a public practice sandbox. This project reads the first three catalogue pages and their linked book pages. It collects titles, prices, availability, ratings, optional descriptions and source information. That scope is appropriate for this sandbox because it was built to let learners practise web scraping on public demo data.

The robots check on 6 November 2026 did not return an HTTP status because the environment could not resolve the host. The status of [robots.txt](https://books.toscrape.com/robots.txt) is unverified. The sandbox's stated purpose is the basis for the target classification.

I will not reuse this code on another site without checking its rules and terms first.
